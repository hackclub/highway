# Benififts

This mainly benefits you if you are having 2 different projects, especially expensive PCBAs.

If you are paying for expensive shipping, you want to do that once. Thus, if you order 1 PCB with, lets say, DHL or UPS shipping, then you want to make sure that you can use the advantages to the maximum. So, by combining orders like this, you can use multiple coupons, one per PCB, while not paying for shipping a gagillion times!
